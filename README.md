# Tempette — versions publiées

Ce dépôt ne contient que les versions de Tempette (le code est privé).

Installer ou réinstaller la dernière version :

```sh
curl -fsSL https://github.com/callbruno/tempette-releases/releases/latest/download/install.sh | sh
```

Ou télécharger le `.dmg` de la [dernière version](https://github.com/callbruno/tempette-releases/releases/latest) : `arm64` pour une puce Apple (M1 à M4), `x64` pour un Mac Intel. Au premier lancement, macOS demande une fois de confirmer dans Réglages › Confidentialité et sécurité › « Ouvrir quand même ».

Les mises à jour s'installent ensuite toutes seules.
