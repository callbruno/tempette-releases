# Tempette — versions publiées

Ce dépôt ne contient que les versions de Tempette (le code est privé).


**👉 Mac avec puce Apple (M1, M2, M3, M4) : [Tempette-Apple-Silicon.dmg](https://github.com/callbruno/tempette-releases/releases/latest/download/Tempette-Apple-Silicon.dmg)**

Mac Intel (plus ancien) : [Tempette-Intel.dmg](https://github.com/callbruno/tempette-releases/releases/latest/download/Tempette-Intel.dmg)

Pas sûr ? Menu  › À propos de ce Mac : « Puce Apple M… » → Apple Silicon, « Processeur Intel » → Intel.

Ouvre le .dmg, glisse Tempette dans Applications, puis lance-la. Au premier lancement, macOS bloque l'app une fois : Réglages Système › Confidentialité et sécurité › **Ouvrir quand même**.

Ou, sans avertissement, dans le Terminal :

```sh
curl -fsSL https://github.com/callbruno/tempette-releases/releases/latest/download/install.sh | sh
```

Les mises à jour s'installent ensuite toutes seules. Les autres fichiers de la liste servent aux mises à jour automatiques : pas besoin d'y toucher.
